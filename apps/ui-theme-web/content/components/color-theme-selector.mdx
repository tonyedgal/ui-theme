## When to use

- Let people choose an app palette without changing light or dark appearance.
- Show readable labels for the palette keys configured on the provider.

- Use the floating menu in headers, toolbars, and compact layouts.

## When not to use

- People are choosing light, dark, or system. Use Theme Selector.
- You need a free-form color picker. This control selects registered palette keys.

## Keyboard

| Key             | Action                                            |
| --------------- | ------------------------------------------------- |
| `Enter / Space` | Open the selector or confirm the focused palette. |
| `Arrow keys`    | Move between palette options.                     |
| `Escape`        | Close the menu and return focus to the trigger.   |

## Accessibility

- Use readable option labels instead of relying on color swatches alone.
- Use option values from `colorThemes`. Custom labels do not register new palettes.

## Theme behavior

- The control calls `switchColorTheme`. The appearance preference does not change.
- Register each palette key on the provider. Define its light and dark CSS variables. Selecting a key does not create its colors.

## Customization

Use `borderStyle="shadow"` in React or `border-style="shadow"` in Vue for prominent shadow borders. The default is `solid`.

Use `slideDirection` only when `animationType` is `ThemeAnimationType.SLIDE`. Set both props on the control when you need a slide direction override.

Pass `animationType`, `duration`, and `slideDirection` to set this control's palette transition.
These props override the provider settings for this action only.

Keyboard focus shows the theme’s focus ring.

Edit the installed source. Use `className` in React or `class` in Vue to style
the root. Use the `classes` prop to style individual parts. Use label props to change the
visible text.
