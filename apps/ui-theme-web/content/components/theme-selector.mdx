## When to use

- Let people choose light, dark, or system appearance in app settings.
- Show the appearance options configured on the provider in one labeled control.

- Use the floating menu in headers, toolbars, and compact layouts.

## When not to use

- A toolbar needs only a quick light/dark action. Use Theme Toggle.
- The choice changes brand colors rather than appearance. Use Color Theme Selector.

## Installation

## Keyboard

| Key             | Action                                           |
| --------------- | ------------------------------------------------ |
| `Enter / Space` | Open the selector or confirm the focused option. |
| `Arrow keys`    | Move between available appearance options.       |
| `Escape`        | Close the menu and return focus to the trigger.  |

## Accessibility

- Keep the label connected to the trigger. Preserve the primitive’s focus behavior.
- The option list comes from the provider. Avoid showing a system option when that option is not configured.

## Theme behavior

- Use `theme` for the selected preference. `System` stays selected when the operating system changes appearance.
- Changes use `switchTheme`. The trigger sets the transition origin. The color palette does not change.

## Customization

Use `borderStyle="shadow"` in React or `border-style="shadow"` in Vue for prominent shadow borders. The default is `solid`.

Use `slideDirection` only when `animationType` is `ThemeAnimationType.SLIDE`. Set both props on the control when you need a slide direction override.

Use `display="icon-text"` to show an icon beside the text. The default is `display="text"`.
For an icon-only action, use [Icon Theme Toggle](/docs/components/base-ui/icon-theme-toggle).
Pass `animationType`, `duration`, and `slideDirection` to this control to set its UI theme transition.
These props override the provider settings for this action only.

Keyboard focus shows the theme’s focus ring.

Edit the installed source. Use `className` in React or `class` in Vue to style
the root. Use the `classes` prop to style individual parts. Use label props to change the
visible text.
