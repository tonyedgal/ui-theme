## When to use

- Use a compact light/dark action in a header or toolbar.
- Use a short icon animation to make the changed state clear.

## When not to use

- People need to choose the system preference. Use Theme Switcher or Theme Selector.
- The control changes a palette. Use Color Theme Selector.

## Installation

Set up [uitheme-web](/docs/installation) in an existing Tailwind app. Then install the component.

## Accessibility

- Keep the accessible label when changing the visible content. Icons are decorative.
- The control stays disabled until the theme provider mounts.
- Reduced motion removes travel and rotation. Icon state keeps a short opacity change. The selection surface changes position without travel.
- Keyboard activation changes the theme without the pointer animation.

## Theme behavior

The sun represents resolved light mode. The moon represents resolved dark mode. Activation replaces a system preference with the opposite resolved theme. The clicked button sets the page transition origin.

## Customization

Use `borderStyle="shadow"` in React or `border-style="shadow"` in Vue for prominent shadow borders. The default is `solid`.

Use `slideDirection` only when `animationType` is `ThemeAnimationType.SLIDE`. Set both props on the control when you need a slide direction override.

Use `effect="rotate"` (default), `effect="slide"`, or `effect="blur"` for the icon exchange. Icon motion lasts 200ms and retargets from its current state on another pointer activation. Use `animationType`, `duration`, and `slideDirection` for the separate UI theme transition. Use native button props, `label`, and `classes` to customize the control.
