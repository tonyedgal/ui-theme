## When to use

- Offer a compact light/dark action in a header, toolbar, or account menu.
- Start an animated appearance change from the control that the person presses.

## When not to use

- People need to choose or return to the system preference. Use Theme Selector.
- People are choosing a color palette. Use Color Theme Selector.

## Keyboard

| Key             | Action                                                 |
| --------------- | ------------------------------------------------------ |
| `Enter / Space` | Toggle between the resolved light and dark appearance. |

## Accessibility

- Keep a meaningful label when changing the visible content.
- The pressed state reports whether the resolved appearance is dark. The control stays disabled until the provider mounts.

## Theme behavior

- The toggle reads `resolvedTheme` and sets a light or dark preference. If the preference was `system`, the toggle replaces it.
- The clicked button sets the origin for `switchTheme`. The engine changes appearance immediately when reduced motion is enabled or transitions are unsupported.

## Customization

Use `borderStyle="shadow"` in React or `border-style="shadow"` in Vue for prominent shadow borders. The default is `solid`.

Use `slideDirection` only when `animationType` is `ThemeAnimationType.SLIDE`. Set both props on the control when you need a slide direction override.

Use `display="icon-text"` to show an icon beside the text. The default is `display="text"`.
For an icon-only action, use [Icon Theme Toggle](/docs/components/base-ui/icon-theme-toggle).
Pass `animationType`, `duration`, and `slideDirection` to this control to set its UI theme transition.
These props override the provider settings for this action only.

Keyboard focus shows the theme’s focus ring.

Edit the installed source. Use `className` in React or `class` in Vue to style
the root. Use the `classes` prop to style individual parts. Use label props to change the
visible text.
