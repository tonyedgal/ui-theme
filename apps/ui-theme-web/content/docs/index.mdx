---
title: UI-Theme v2
description: One runtime for React, Vue, Next.js, TanStack Start, and Nuxt 4.
---

Install the runtime once. Choose the import for your framework.
UI-Theme manages appearance, palettes, persistence, and animated theme transitions.
Styled controls are source files that you install separately.

```sh
npm install uitheme-web@^2
```

| Environment                      | Import                              |
| -------------------------------- | ----------------------------------- |
| Framework-neutral browser engine | `uitheme-web` or `uitheme-web/core` |
| React                            | `uitheme-web/react`                 |
| Next.js client provider          | `uitheme-web/next`                  |
| Next.js server bootstrap         | `uitheme-web/next/server`           |
| TanStack Start server helpers    | `uitheme-web/tanstack`              |
| Vue 3                            | `uitheme-web/vue`                   |
| Vue server bootstrap             | `uitheme-web/vue/bootstrap`         |
| Nuxt 4 module                    | `uitheme-web/nuxt`                  |

The runtime has no UI primitive dependency. Framework dependencies are optional peers.
Install React or Vue in the app that uses that adapter.
