## Install

```sh
npm install uitheme-web@latest
```

## Create a client provider

```tsx title="app/providers.tsx"
'use client';

import { NextUIThemeProvider } from 'uitheme-web/next';

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <NextUIThemeProvider defaultTheme="system">{children}</NextUIThemeProvider>
  );
}
```

## Wrap your root layout

Keep the layout as a Server Component. The provider includes the script that applies the saved appearance before hydration.

```tsx title="app/layout.tsx"
import './globals.css';
import { Providers } from './providers';

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

Keep theme hooks and interactive controls in Client Components. Use `uitheme-web/next/server` when you need server-safe bootstrap helpers. Do not import browser hooks into server code.

## Provider options

`NextUIThemeProvider` accepts these options for transitions and security.

| Prop                        | Default | Behavior                                                                                                                                  |
| --------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `disableTransitionOnChange` | `false` | When `true`, `setTheme` and `setColorTheme` switch off CSS transitions for the change. The provider restores them right after the change. |
| `nonce`                     | none    | Sets the `nonce` on the inline bootstrap script. Also sets it on every `<style>` element that the library injects for transitions.        |

`disableTransitionOnChange` does not apply to `switchTheme`, which runs an animated transition.

Use `nonce` with a `style-src 'nonce-…'` Content Security Policy. Pass the same nonce that your server sends in the policy header.

```tsx
<NextUIThemeProvider nonce={nonce} disableTransitionOnChange>
  {children}
</NextUIThemeProvider>
```
